# Data sources

## BCI Competition IV Dataset 2a

Используется для экспериментов по motor imagery classification.

- 9 subjects
- 22 EEG channels
- binary Left Hand / Right Hand task
- strict LOSO evaluation

Official source:
https://www.bbci.de/competition/iv/

## PhysioNet EEG Motor Movement/Imagery Dataset

Используется для внешней проверки и полномасштабных subject-independent экспериментов.

- 109 subjects
- 64 EEG channels
- binary Left Hand / Right Hand task
- strict LOSO evaluation

Official source:
https://physionet.org/content/eegmmidb/

## Cho2017

Используется для предварительного обучения EEGNet и последующего transfer learning.

## EEGDenoiseNet

Использовался на ранних этапах исследования методов подавления EOG/EMG artifacts.

Raw datasets are not included in this repository.
