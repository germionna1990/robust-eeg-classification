# Model checkpoints

Обученные веса моделей не хранятся в GitHub-репозитории.

Основные checkpoints, используемые в исследовании:

- `pretrained_exact_eegnet_v2.pth` — pretrained EEGNet;
- `cho2017_binary_unified_eegnet.pt` — binary EEGNet pretrained on Cho2017;
- `cho2017_task_informed_pretrained_full.pt` — task-informed pretrained model;
- `cho64_eegnet64_best.pt` — 64-channel EEGNet pretrained on Cho2017;
- `multichannel_bci_denoiser.pt` — multichannel BCI denoiser;
- `taskaware_multichannel_denoiser.pt` — task-aware multichannel denoiser.

Checkpoints are stored separately in the research artifact folder for NIR 3.
